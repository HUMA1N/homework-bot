# homework-bot

Telegram-бот для учёта домашки. Пишешь ему обычным сообщением — он сам разбирает
предмет и срок, запоминает задание и потом напоминает о нём.

```
ты:   алгебра №245 на завтра
бот:  📌 Записал!
      Завтра — ср, 7 октября
      ⬜ Алгебра — №245
      [✅ Сделано] [🗑 Удалить]
```

**Что умеет**

- Понимает задания в свободной форме: `алгебра №245 на завтра`,
  `история параграф 12 к пятнице`, `дз по англу стр 34 до 15.10`,
  `литература читать Онегина к 20 октября`, `физра форма к следующему понедельнику`.
  Можно прислать несколько заданий сразу — каждое с новой строки.
- **Знает расписание уроков.** Задай его один раз командой `/schedule`, и задание
  без срока, «к следующему уроку» или «на завтра», когда завтра этого урока нет,
  бот поставит на ближайший урок по этому предмету. Без расписания ставит на завтра.
- **Фото задания.** Пришли фото с подписью `геометрия №12 на завтра`, и бот прикрепит
  его к записи. В списках у такого задания будет 📷 и кнопка, чтобы открыть фото.
- **Статистика.** `/stats` покажет, сколько заданий сделано за неделю, по предметам.
- **Утром** (по умолчанию в 07:30) присылает список на сегодня.
- **Вечером** (по умолчанию в 20:00) напоминает о том, что ещё не сделано.
- Под каждым списком есть кнопки: нажми **✅**, когда сделал задание.
  Если нажал по ошибке, нажми **↩️**, и задание вернётся в список.
- Команды: `/today` — на сегодня, `/tomorrow` — на завтра, `/week` — всё на неделю,
  `/all` — все невыполненные, `/stats` — статистика за неделю, `/schedule` — расписание
  уроков, `/cancel` — отменить ввод расписания или фото, `/help` — подсказка.

Задания хранятся в файле `homework.db` (база SQLite) рядом с ботом.

> Бот на домашнем компьютере работает, только пока компьютер включён.
> Чтобы он работал круглосуточно, запусти его на сервере: инструкция
> в [DEPLOY.md](DEPLOY.md).

## Запуск на Windows: пошагово

Понадобится около 15 минут. Программировать ничего не нужно, только повторять шаги.

### Шаг 1. Создай бота у BotFather и получи токен

1. Открой Telegram (на телефоне или компьютере).
2. Найди в поиске **@BotFather**. Это официальный бот Telegram для создания ботов,
   у него синяя галочка рядом с именем.
3. Нажми **Start** (или **Запустить**).
4. Отправь ему команду `/newbot`.
5. BotFather спросит **имя бота**. Это то, что будет видно в списке чатов, например
   `Моя домашка`. Отправь его.
6. Потом он спросит **username**, адрес бота. Он должен быть на латинице,
   уникальным и заканчиваться на `bot`, например `masha_homework_bot`.
   Если имя занято, BotFather попросит придумать другое.
7. В ответ придёт сообщение с **токеном**. Это длинная строка вида
   `1234567890:AAH...xyz`. Скопируй её целиком.

> ⚠️ **Токен — это пароль от бота.** Кто его знает, тот может управлять ботом.
> Не отправляй его никому и не выкладывай в интернет (в том числе на GitHub).
> Если токен всё-таки утёк: напиши @BotFather `/mybots` → выбери бота →
> **API Token** → **Revoke current token**. Старый токен перестанет работать,
> а BotFather выдаст новый.

### Шаг 2. Установи Python

1. Открой <https://www.python.org/downloads/> и нажми большую жёлтую кнопку
   **Download Python 3.x.x**. Подойдёт версия от 3.10 до 3.14, проще всего взять ту,
   что предлагает сайт.
2. Запусти скачанный файл.
3. **Важно:** внизу первого окна установщика поставь галочку
   **Add python.exe to PATH**. Потом нажми **Install Now**.
4. Дождись конца установки и нажми **Close**.

Проверим, что всё установилось. Нажми **Win + R**, введи `cmd` и нажми Enter.
Откроется чёрное окно, это **командная строка**. Введи в ней:

```
py --version
```

Должно появиться что-то вроде `Python 3.13.1`. Если пишет
«'py' не является внутренней или внешней командой», переустанови Python
и не забудь про галочку из пункта 3.

### Шаг 3. Скачай бота

1. Открой страницу этого репозитория на GitHub.
2. Нажми зелёную кнопку **Code** → **Download ZIP**.
3. Распакуй архив в удобное место, например в `C:\homework-bot`.
   Внутри папки должны лежать файлы `bot.py`, `requirements.txt` и папка `homework_bot`.

> Если умеешь пользоваться git, можно вместо этого выполнить
> `git clone <адрес репозитория>`.

### Шаг 4. Открой командную строку в папке бота

1. Открой папку бота в Проводнике. Это та папка, где лежит `bot.py`.
2. Кликни по **адресной строке** Проводника вверху (где написан путь к папке),
   сотри путь, напиши `cmd` и нажми Enter.

Откроется командная строка, уже «стоящая» в папке бота. Слева будет виден путь,
например `C:\homework-bot>`. Все команды дальше вводятся в этом окне.

### Шаг 5. Установи библиотеки

Введи по очереди эти команды. После каждой нажимай Enter и жди, пока она закончится:

```
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Что происходит:

- первая команда создаёт «виртуальное окружение», то есть отдельную папку `.venv`
  с библиотеками только для этого бота;
- вторая включает его, и слева в строке появится `(.venv)`;
- третья скачивает библиотеки, нужные боту (aiogram и другие).

> Эти команды для **командной строки (cmd)**. Если ты открыл PowerShell
> (строка начинается с `PS`), вторая команда выглядит так:
> `.venv\Scripts\Activate.ps1`. Если PowerShell ругается на «выполнение сценариев
> отключено», просто открой cmd, как описано в шаге 4.

### Шаг 6. Впиши токен

Токен хранится в файле `.env`, который **не попадает в git**: он указан в
`.gitignore`. Так токен не утечёт, даже если ты выложишь код на GitHub.

1. Создай файл `.env` из шаблона:

   ```
   copy .env.example .env
   ```

2. Открой его в Блокноте:

   ```
   notepad .env
   ```

3. Найди строку `BOT_TOKEN=` и вставь токен из шага 1 сразу после знака `=`,
   без пробелов и кавычек:

   ```
   BOT_TOKEN=1234567890:AAH...xyz
   ```

4. Сохрани файл (**Ctrl + S**) и закрой Блокнот.

<details>
<summary>Другой способ: переменная окружения вместо файла .env</summary>

Бот берёт токен из переменной окружения `BOT_TOKEN`. Файл `.env` — просто удобный
способ её задать. Можно задать переменную и напрямую.

Только для текущего окна командной строки:

```
set BOT_TOKEN=1234567890:AAH...xyz
```

Навсегда для твоего пользователя Windows (сработает в **новых** окнах cmd):

```
setx BOT_TOKEN "1234567890:AAH...xyz"
```

Если переменная задана, она главнее значения из `.env`.
</details>

### Шаг 7. Запусти бота

```
python bot.py
```

Если всё хорошо, появится строка вроде:

```
12:00:00 INFO homework_bot.app: Бот @masha_homework_bot запущен. Утренняя рассылка в 07:30, вечерняя в 20:00. Остановить: Ctrl+C
```

Теперь открой своего бота в Telegram (найди его по username из шага 1),
нажми **Start** и отправь, например, `алгебра №245 на завтра`. 🎉

**Бот работает, пока открыто это окно и включён компьютер.** Если закрыть окно
или выключить компьютер, бот перестанет отвечать. Когда запустишь его снова,
он ответит на сообщения, пришедшие за это время (Telegram хранит их сутки).

Если компьютер спал во время утренней или вечерней рассылки, бот отправит её после
пробуждения, но только если опоздание не больше трёх часов.

Остановить бота: нажми **Ctrl + C** в окне командной строки.

### Как запустить снова (в следующий раз)

Устанавливать ничего не нужно. Открой командную строку в папке бота (шаг 4) и введи:

```
.venv\Scripts\activate
python bot.py
```

## Как писать задания

Бот ищет в сообщении **предмет** и **срок**, а всё остальное считает самим заданием.

| Что пишешь | Что поймёт бот |
|---|---|
| `алгебра №245 на завтра` | Алгебра · №245 · завтра |
| `история параграф 12 к пятнице` | История · параграф 12 · ближайшая пятница |
| `дз по русскому упр 45 до среды` | Русский язык · упр 45 · ближайшая среда |
| `англ стр 34 к следующему понедельнику` | Английский язык · стр 34 · понедельник следующей недели |
| `литература стих наизусть к 20 октября` | Литература · стих наизусть · 20 октября |
| `химия задача 3 к 15.10` | Химия · задача 3 · 15 октября |
| `геом №12 через 3 дня` | Геометрия · №12 · через 3 дня |
| `физика задачи 3–5 к следующему уроку` | Физика · задачи 3–5 · ближайший урок физики |
| `физра форма` | Физкультура · форма · ближайший урок (или завтра, если нет расписания) |

**Предметы** можно писать полностью, сокращённо и в любом падеже: «алгебра»,
«алг», «по алгебре», «рус яз», «англ», «лит-ра», «общага», «инфа», «физра» и так далее.
Если предмета нет в списке, бот возьмёт первое слово сообщения: из
`хореография растяжка на завтра` получится предмет «Хореография».

**Сроки:**

- `сегодня`, `завтра`, `послезавтра`;
- дни недели: `к пятнице`, `на среду`, `до четверга`, `в пн`, `к следующей пятнице`;
- даты: `к 20 октября`, `к 15.10`, `до 15/10`, `на 15.10.2026`, `к 15-му`;
- `через 3 дня`, `через неделю`;
- `к следующему уроку`, `на след. урок`, `к уроку` — ближайший урок по расписанию.

Дату цифрами без года пиши с предлогом: `к 15.10`, а не просто `15.10`.
Иначе бот может принять её за номер упражнения вроде `упр 12.3`.

Если бот понял что-то не так, нажми **🗑 Удалить** под ответом и напиши задание
по-другому.

## Расписание уроков

Отправь боту `/schedule`, а следующим сообщением — расписание. Каждый день
с новой строки, уроки через запятую:

```
пн: алгебра, русский, история, англ
вт: физика, литература, геометрия
ср: химия, алгебра, биология
чт: русский, англ, информатика
пт: геометрия, история, физра
```

Можно и столбиком, как в дневнике: строка с днём недели, под ней уроки. Номера уроков
и время (`1. 8:30 Алгебра`) бот пропустит сам. Предметы пишутся так же свободно, как
в заданиях: «алг», «рус яз», «физра».

После этого:

| Что пишешь | Куда поставит бот |
|---|---|
| `алгебра №245` (без срока) | на ближайший урок алгебры |
| `физика задачи 3–5 к следующему уроку` | на ближайший урок физики |
| `история §12 на завтра`, а завтра истории нет | на ближайший урок истории (бот предупредит) |
| `история §12 на завтра`, и завтра есть история | на завтра |
| `алгебра №245 к пятнице` | на пятницу: точная дата важнее расписания |
| предмета нет в расписании | на завтра |

«Ближайший урок» — это урок **после** сегодняшнего дня: задание, которое задали
сегодня, сегодня уже не сдают.

Посмотреть расписание — снова `/schedule`. Чтобы изменить, пришли новое: оно
заменит старое. Чтобы удалить, после `/schedule` напиши `очистить`.

## Фото задания

- **Фото с подписью.** Сфотографируй задание и в подписи напиши, что это:
  `геометрия №12 на завтра`. Бот запишет задание и прикрепит к нему фото.
  Можно отправить несколько фото разом (альбомом) — все прикрепятся к одному заданию.
- **Фото без подписи.** Бот попросит написать, что это за задание, и прикрепит фото
  к следующему твоему заданию.
- **Ответом на сообщение бота.** Если задание уже записано, ответь (Reply) фотографией
  на сообщение бота «📌 Записал!» — фото прикрепится к этому заданию.

Подходят обычные фото, картинки и PDF-файлы. В списках (`/today`, `/week`, `/all`, утром
и вечером) у заданий с фото стоит 📷, а рядом с кнопкой «сделано» — кнопка **📷**:
нажми её, и бот пришлёт фото.

Сами фото хранятся в Telegram, бот запоминает только ссылки на них, поэтому база
почти не растёт.

## Статистика

`/stats` показывает, сколько заданий ты отметил ✅ за последние 7 дней, по предметам,
и сколько ещё не сделано (и из них просрочено).

## Настройки

Все настройки лежат в файле `.env` (или в переменных окружения с теми же именами):

| Настройка | Что значит | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | токен бота от @BotFather | — (обязательно) |
| `MORNING_TIME` | во сколько присылать список на сегодня | `07:30` |
| `EVENING_TIME` | во сколько напоминать о невыполненном | `20:00` |
| `TIMEZONE` | часовой пояс, например `Europe/Moscow` | часовой пояс компьютера |
| `DB_PATH` | где хранить базу с заданиями | `homework.db` в папке бота (на сервере — `/var/lib/homework-bot/homework.db`) |

После изменения `.env` перезапусти бота: нажми Ctrl + C и снова `python bot.py`.

## Если что-то не работает

| Сообщение | Что делать |
|---|---|
| `'py' не является внутренней или внешней командой` | Переустанови Python с галочкой **Add python.exe to PATH** (шаг 2). |
| `No module named 'aiogram'` | Ты забыл включить окружение. Выполни `.venv\Scripts\activate`, а потом снова `python bot.py`. |
| `Не задан токен бота` | Нет файла `.env` или в нём пустой `BOT_TOKEN` (шаг 6). Проверь, что файл называется именно `.env`, а не `.env.txt`. Чтобы увидеть настоящее имя, включи в Проводнике **Вид → Показать → Расширения имён файлов** (в Windows 10: **Вид → Расширения имён файлов**). |
| `Telegram не принял токен бота` | Токен скопирован с ошибкой или его отозвали. Возьми актуальный у @BotFather: `/mybots` → бот → **API Token**. |
| `Не удалось подключиться к Telegram` | Проверь интернет. Если Telegram в твоей сети заблокирован, бот не сможет к нему подключиться. |
| `TelegramConflictError` | Бот запущен два раза (например, в двух окнах). Закрой лишнее окно. |
| Задания без срока ставятся на завтра, хотя расписание задано | Предмета нет в расписании или он записан по-другому. Отправь `/schedule` и проверь, как бот понял расписание. |
| Бот не присылает утренний список | Утренний список приходит, только если компьютер включён и бот запущен в это время. Ещё нужно хотя бы раз написать боту `/start` или любое задание. |

## Для разработчиков

### Структура

```
bot.py                   точка входа: python bot.py
homework_bot/
  parser.py              разбор сообщений: предмет, задание, срок (без Telegram)
  schedule.py            разбор и вывод расписания уроков
  storage.py             хранение заданий, фото и расписания в SQLite
  views.py               списки заданий, статистика: тексты и кнопки
  handlers.py            команды, сообщения, фото, нажатия кнопок (aiogram 3)
  reminders.py           утренняя и вечерняя рассылка
  config.py              настройки из переменных окружения / .env
  app.py                 сборка и запуск бота
deploy/
  homework-bot.service   служба systemd для круглосуточной работы на сервере
  install.sh             установка на сервер (см. DEPLOY.md)
  update.sh              обновление на сервере
.github/workflows/
  tests.yml              GitHub Actions: тесты на каждый push и pull request
tests/
  test_parser.py         тесты разбора сообщений
  test_schedule.py       тесты расписания и сроков «к ближайшему уроку»
  test_bot_logic.py      тесты хранилища, списков и времени рассылок
  test_handlers.py       бот целиком: сообщения, фото, кнопки (Telegram подменён)
```

### Тесты

```
pip install -r requirements-dev.txt
pytest
```

Те же тесты запускает GitHub Actions на каждый push и pull request (Python 3.10–3.14,
Linux и Windows), а ещё проверяет скрипты из `deploy/`. Результат — на вкладке
**Actions** репозитория и зелёной/красной галочкой у коммита.

### Как добавить предмет

Открой `homework_bot/parser.py` и допиши строку в словарь `SUBJECTS`: название
предмета и регулярные выражения для вариантов написания. Например:

```python
"Робототехника": [r"робототехник\w*", r"робот\w*"],
```

`\w*` означает «любое окончание», поэтому выражение подойдёт и для
«робототехника», и для «по робототехнике». Не забудь добавить тест в
`tests/test_parser.py`.
