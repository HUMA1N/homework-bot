# Круглосуточная работа на сервере (VPS с Linux)

На домашнем компьютере бот работает, только пока компьютер включён. Чтобы бот отвечал
и присылал напоминания всегда, его запускают на **VPS** — арендованном сервере
в интернете, который никогда не выключается. Бот будет работать там как
**systemd-служба**: сам запустится после перезагрузки сервера и сам перезапустится,
если упадёт.

Понадобится около 20 минут. Все команды ниже можно копировать и вставлять.

## Что понадобится

- **VPS с Ubuntu 22.04 / 24.04 или Debian 12.** Хватит самого дешёвого тарифа:
  1 процессор и 512 МБ памяти. При заказе выбери операционную систему Ubuntu.
  Важно, чтобы Telegram был доступен с сервера — выбирай сервер в стране, где
  Telegram не заблокирован.
- От хостинга ты получишь **IP-адрес** сервера (вида `203.0.113.10`) и **пароль
  пользователя root**. Обычно их присылают на почту или показывают в личном кабинете.
- Токен бота от @BotFather — тот же, что в файле `.env` на компьютере.

> ⚠️ Один и тот же бот нельзя запускать в двух местах сразу. Перед запуском на сервере
> **останови бота на компьютере** (Ctrl + C в окне командной строки), иначе в журнале
> будет ошибка `TelegramConflictError`.

## Шаг 1. Подключись к серверу из Windows

В Windows 10 и 11 уже есть программа `ssh` для подключения к серверам.

1. Нажми **Win + R**, введи `cmd` и нажми Enter.
2. Введи команду, подставив IP-адрес своего сервера:

   ```
   ssh root@203.0.113.10
   ```

3. При первом подключении спросят `Are you sure you want to continue connecting?` —
   напиши `yes` и нажми Enter.
4. Введи пароль root. **Символы при вводе пароля не отображаются** — это нормально.
   Вставить пароль из буфера можно правой кнопкой мыши. Потом нажми Enter.

Если всё получилось, строка станет похожа на `root@my-server:~#`. Теперь все команды,
которые ты вводишь в этом окне, выполняются **на сервере**, а не на компьютере.
Отключиться от сервера: команда `exit`.

## Шаг 2. Скачай бота на сервер

Установи git и скачай бота в папку `/opt/homework-bot`:

```
apt update && apt install -y git
git clone https://github.com/HUMA1N/homework-bot.git /opt/homework-bot
cd /opt/homework-bot
```

<details>
<summary>Если репозиторий приватный и git просит логин и пароль</summary>

Проще всего загрузить бота с компьютера:

1. На странице репозитория на GitHub нажми **Code** → **Download ZIP**.
2. Открой **новое** окно cmd на компьютере (не то, где подключён сервер), перейди в папку
   «Загрузки» и отправь архив на сервер:

   ```
   cd %USERPROFILE%\Downloads
   scp homework-bot-main.zip root@203.0.113.10:/opt/
   ```

3. В окне, где подключён сервер, распакуй архив:

   ```
   apt update && apt install -y unzip
   cd /opt && unzip homework-bot-main.zip && mv homework-bot-main homework-bot
   cd /opt/homework-bot
   ```

Так скачанного бота обновляют тем же способом: заново загрузить архив, распаковать
поверх и запустить `bash deploy/install.sh`. Команда `deploy/update.sh` работает
только для бота, скачанного через git.
</details>

## Шаг 3 (по желанию). Перенеси задания с компьютера

Если бот уже работал на компьютере и там есть записанные задания, перенеси файл базы.
В **новом** окне cmd на компьютере перейди в папку бота и отправь файл на сервер:

```
cd C:\homework-bot
scp homework.db root@203.0.113.10:/opt/homework-bot/
```

Установщик на следующем шаге сам переложит базу куда нужно. Если заданий нет,
пропусти этот шаг: бот создаст новую базу.

## Шаг 4. Установи бота как службу

В окне, где подключён сервер:

```
bash deploy/install.sh
```

> Если ты зашёл на сервер не как root, а как обычный пользователь,
> пиши `sudo` в начале этой и остальных команд: `sudo bash deploy/install.sh`.

Установщик:

1. установит Python, если его нет;
2. создаст системного пользователя `homework`, от имени которого будет работать бот
   (так безопаснее, чем от root);
3. установит библиотеки;
4. **спросит токен бота** — вставь его правой кнопкой мыши и нажми Enter;
5. **спросит часовой пояс** — просто нажми Enter для московского времени или впиши
   свой, например `Asia/Yekaterinburg`. Это важно: на серверах обычно стоит время UTC,
   и без часового пояса утренний список пришёл бы не в 07:30 по-твоему;
6. установит и запустит службу `homework-bot`.

В конце должна появиться надпись **«Готово! Бот работает…»**. Напиши боту в Telegram —
он ответит. Окно с сервером теперь можно закрыть: бот продолжит работать.

## Управление ботом

Подключись к серверу (шаг 1) и используй команды:

| Что сделать | Команда |
|---|---|
| Проверить, работает ли бот | `systemctl status homework-bot` (выход — клавиша `q`) |
| Смотреть журнал бота | `journalctl -u homework-bot -f` (выход — Ctrl + C) |
| Последние 50 строк журнала | `journalctl -u homework-bot -n 50` |
| Перезапустить | `systemctl restart homework-bot` |
| Остановить | `systemctl stop homework-bot` |
| Запустить | `systemctl start homework-bot` |
| Обновить до новой версии с GitHub | `bash /opt/homework-bot/deploy/update.sh` |

### Изменить настройки

Настройки лежат в том же файле `.env`, что и на компьютере (таблица настроек —
в [README.md](README.md#настройки)). Открой его в редакторе nano:

```
nano /opt/homework-bot/.env
```

Измени нужную строку, сохрани (**Ctrl + O**, потом Enter) и выйди (**Ctrl + X**).
Затем перезапусти бота: `systemctl restart homework-bot`.

### Где лежат задания и как сделать резервную копию

База с заданиями на сервере — `/var/lib/homework-bot/homework.db`. Чтобы скачать её
на компьютер, в **новом** окне cmd на компьютере выполни:

```
scp root@203.0.113.10:/var/lib/homework-bot/homework.db homework-backup.db
```

Файл `homework-backup.db` появится в текущей папке.

## Если что-то не работает

Сначала посмотри журнал: `journalctl -u homework-bot -n 50`. В нём те же сообщения
об ошибках, что были бы в окне командной строки на компьютере, — их разбор есть
в [README.md](README.md#если-что-то-не-работает).

| Что видно | Что делать |
|---|---|
| `TelegramConflictError` | Бот запущен ещё где-то, например на компьютере. Останови его там. |
| `Не удалось подключиться к Telegram` | С сервера недоступен Telegram. Проверь: `curl -I https://api.telegram.org` — если ответа нет, нужен сервер в другой стране. |
| `Telegram не принял токен бота` | Исправь `BOT_TOKEN` в `.env` (см. «Изменить настройки») и перезапусти бота. |
| Утренний список приходит не в то время | Проверь `TIMEZONE` в `.env`, например `TIMEZONE=Europe/Moscow`, и перезапусти бота. |
| `bash: deploy/install.sh: No such file or directory` | Ты не в папке бота. Выполни `cd /opt/homework-bot`. |
| `$'\r': command not found` | Скрипт испортился при редактировании в Windows. Скачай бота заново (шаг 2). |

Служба сама перезапускает бота через 10 секунд после любого сбоя, например пока на
сервере пропал интернет. Поэтому временные ошибки в журнале не страшны: главное,
чтобы `systemctl status homework-bot` показывал `active (running)`.

## Как удалить бота с сервера

```
systemctl disable --now homework-bot
rm /etc/systemd/system/homework-bot.service
systemctl daemon-reload
rm -rf /opt/homework-bot /var/lib/homework-bot
userdel homework
```

## Для любопытных: что внутри

- `deploy/homework-bot.service` — описание службы для systemd: от какого пользователя
  запускать, какую команду, что делать при сбое. Бот может писать только в свою папку
  `/var/lib/homework-bot`, остальная система для него закрыта.
- `deploy/install.sh` — установщик. Его можно запускать повторно: он не сотрёт
  ни настройки, ни задания.
- `deploy/update.sh` — скачивает новую версию через `git pull` и запускает установщик.
